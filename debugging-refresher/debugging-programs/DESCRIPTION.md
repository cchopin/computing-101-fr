Ce défi remet GDB en main.
Pour commencer ce défi, comme tous les autres défis de ce module, lancer `/challenge/embryogdb_levelXYZ`, où XYZ est le numéro du niveau.
Ce programme lance `gdb`.
Exécuter la logique du niveau avec `r`, puis suivre les consignes pour obtenir le flag !
